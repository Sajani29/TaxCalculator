# Tax Calculator System

A Java-based Command Line Interface (CLI) application developed to calculate different types of taxes and leasing payments efficiently. This project was developed as coursework for the Institute of Computer Engineering Technology (iCET).

## 📌 Features

### 💰 Withholding Tax
- Rent Tax Calculation
- Bank Interest Tax Calculation
- Dividend Tax Calculation

### 🧾 Payable Tax
- Monthly payable tax calculation based on salary ranges

### 📊 Income Tax
- Annual income tax calculation using tax brackets

### 🏢 SSCL Tax
- Social Security Contribution Levy calculation
- Includes Sale Tax and VAT calculations

### 🚗 Leasing Payment Calculator
- Calculate Monthly Installment
- Search Leasing Categories
- Find Available Leasing Amount

## ✅ Functionalities
- User-friendly CLI interface
- Input validation for all user inputs
- Menu-driven navigation system
- Tax calculations based on Sri Lankan tax rules
- Recalculate or return-to-menu options

## 🛠️ Technologies Used
- Java
- Scanner Class
- Object-Oriented Programming Concepts
- Command Line Interface (CLI)
